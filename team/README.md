# The team, as files

One file per role with the rules it enforces and the mistake behind each. Two roles fill every seat today; when a
question needs an expert's view the build agent reads the matching role of the SG/Send team
(https://github.com/the-cyber-boardroom/SGraph-AI__App__Send/tree/dev/team/roles) and answers in that role.

- [project-lead.md](roles/project-lead.md): Dinis Cruz; the brief, acceptance, credentials, DNS, Pages.
- [build-agent.md](roles/build-agent.md): a Claude session per task; code, tests, site, gate, release.

The board is files: the proposed rows of `website/data/features.json` are the backlog, `BRIEF-CORRECTIONS.md` the
findings, and `/about/needs/` on the site the lead's queue.
