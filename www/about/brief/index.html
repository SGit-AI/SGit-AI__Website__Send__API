The agent's reading of the four memos

  1. Move SG/Send to sgit.ai as send.sgit.ai: the same job (send data from A to B, encrypted in the browser, the server never sees a key) with the two things that were missing and are now solved, somewhere to keep the vault keys and files kept in vaults rather than one-shot transfers, and QR codes as the first way to hand a link over.
  2. Split the code from the site: api.send.sgit.ai is the versioned, released, embeddable code that send.sgit.ai uses and that other places can embed; the site is the usage, the examples and the commercial model.
  3. Version it as independent releases: every minor release is a complete copy of the code, no overlays, each quality-controlled; refactoring happens at the major. An article on this pattern, which the newsroom's API already follows.
  4. A centralised guidance page on every site carrying its own /articles/: agents writing what they delivered, and articles written from voice memos on that site's own dimension; one page to point every agent at, published where sgit.ai can import it.
