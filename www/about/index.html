About this repository

api.send.sgit.ai is the client-side API behind send.sgit.ai: the code a browser runs to encrypt a file, keep its name inside the ciphertext, upload it as a transfer or commit it into a vault, draw the link as a QR code, and keep the keys on the device. It is published as releases a page pins by address. The repository is SGit-AI__Website__Send__API.

It follows what every sgit repository carries:

ThingWhere
The brief, in full/about/brief/, from briefs/
The reality file/about/reality/, from website/data/features.json
The corrections file/about/corrections/, BRIEF-CORRECTIONS.md
One version, going up on every pushtools/version.json, shown in every header, the history
