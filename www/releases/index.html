Releases

A release is a directory under /vX.Y.Z/ on this host, served exactly as it is in the repository, with a manifest.json of every file's size and SHA-256. The current one is named in /releases.json. A change to the code is the next directory, never an edit of this one; independent releases is the rule and the reason.
