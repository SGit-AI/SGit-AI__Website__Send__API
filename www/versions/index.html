Every change that lands on main is a version, in tools/version.json, tagged by the deploy and shown in the header of every page. The release column is the cut of the code a site pins; it moves only when a served file changes.

v0.1.02026-10-20releasethe first release: the modules send.sgit.ai runs, as one independent directory, with its tests and the server in memory. From the four voice memos of 20 October 2026 (the brief, published in full). The modules: AES-256-GCM crypto with the SGMETA envelope, friendly tokens with the derivations send.sgraph.ai uses, the link grammar, the transfer client with send() and receive(), QR codes as SVG, the vault layer over the vendored library (publish with compare-and-swap, never push()), and the per-device keyring. 43 tests run in Node against the in-memory server; a browser smoke test runs the same modules in Chromium. The website, the gate and the release tooling come with it.
